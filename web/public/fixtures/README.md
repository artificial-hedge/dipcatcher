# Web fixture data — provenance, regeneration, and honesty labeling

**Everything in this directory is a generated export of committed research
evidence. It is tracked in git ON PURPOSE**, and every file here can be
regenerated from the repo. Never edit fixtures by hand.

## Where fixtures come from

Generated by [`web/scripts/export_fixtures.py`](../../scripts/export_fixtures.py)
(sources are read-only; `receipts/` and `artifacts/` are never modified):

| Fixture | Source | Kind |
|---|---|---|
| `receipts/*.json` | `receipts/*.json` | **verbatim byte copies** of committed research receipts (the immutable evidence store) |
| `strategies/*.json` | `artifacts/carry_champion*.json` and `receipts/legacy-unsealed/adaptive_mix_20asset_1d_20260922.json` | normalized strategy summaries; each fixture records its source provenance |
| `equity/*.json` | `artifacts/*equity*.parquet` | mechanical row-wise JSON export of committed simulated-equity panels |
| `index.json` | derived | manifest the app loads first: sha-256 → repo-path match table (`hash_matches`), strategy/receipt listings, honesty block |

Regenerate after any sealed, intentional change to `receipts/` or `artifacts/`:

```bash
uv run --no-sync python web/scripts/export_fixtures.py          # rewrite exports
uv run --no-sync python web/scripts/export_fixtures.py --check  # freshness gate
```

`--check` regenerates into a scratch directory and exits non-zero when any
fixture is **missing, stale, or extra**. Run it as a local freshness check;
the current CI workflows do not invoke it. Commit regenerated fixtures
together with the source change that caused them.

## Honesty labeling (contract — do not weaken)

- These are **real, committed research evidence mirrors**, not synthetic demo
  data. The authoritative, immutable store is the top-level `receipts/`
  directory; if a fixture and `receipts/` ever disagree, `receipts/` wins and
  the fixture is stale (`--check` fails).
- Research-claim posture is carried in `index.json` → `honesty`:
  `research_only: true`, `live_pnl_claim: false`. The UI renders stored fields
  and makes **no performance or live-trading claims**.
- Where a source artifact records `data_source: SYNTHETIC`, the UI renders it
  with a distinct `synthetic` badge (see `OverviewPage`); SYNTHETIC results are
  correctness checks, never market evidence.
- No fixture may introduce a headline Sharpe/Sortino/Calmar/P&L/NAV metric.
  Performance numbers rendered from these fixtures live only inside the
  collapsed “Historical simulation diagnostics (not research headline
  evidence)” panel, labeled “as recorded”. Proper scores only for research
  headlines (pinball, CRPS, PIT, QLIKE, Brier, ECE, Kupiec, HMM likelihood).
