# until a row is added here or the handler fails closed.
#
# Not listed, on purpose:
# - ImportError -> {} when a scorecard lane's module is optional.
# - ValueError / RuntimeError / FloatingPointError / TypeError -> {}
#   when a lane cannot be constructed or a score is non-finite.
#   KeyError is not in that degrade: a renamed required score is a bug.
# - contextlib.suppress(OSError) around cleanup.
# - forward_shadow's suppress(ValueError, sqlite3.Error) around a
#   failure-journal write that still re-raises the original error.
# - .get(symbol, 0) / .get(name, {}) for optional subsections, zero
#   baselines, and absent persisted lists. A .get of candidates,
#   provenance, health, promotion, or synthetic_coverage with an empty
#   default is a swallow and must be a row.
